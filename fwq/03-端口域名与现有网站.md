# 03：端口、域名与现有网站

| 端口 | 常见用途 |
| --- | --- |
| `22` | SSH 远程登录 |
| `80` | HTTP 网站 |
| `443` | HTTPS 网站 |

这台服务器的 80 端口已有网站。不要让新程序直接占用 80 端口，也不要停止现有 Web 服务。

## 登录服务器后检查

```bash
ss -lntp | grep -E ':22|:80|:443'
systemctl status nginx
systemctl status apache2
systemctl status httpd
```

有些服务不存在很正常，不要为了测试而启动它们。若安装了 Nginx，可运行 `nginx -T` 展开配置，重点找 `server_name`、`listen`、`root` 和 `proxy_pass`。

## 在 Windows 检查域名

```powershell
nslookup dentrobot.com
curl.exe -I http://dentrobot.com
curl.exe -I https://dentrobot.com
```

DNS 结果包含 `104.168.22.222` 才表示域名指向这台服务器。解析、网站部署、ICP备案和 HTTPS 是四件不同的事。

服务器内部可测试：

```bash
curl -I http://127.0.0.1
```

`200` 表示成功；`301/302` 表示跳转；`404` 表示路径不存在；`502` 常表示反向代理找不到后端。

若服务器位于中国大陆并用于正式互联网服务，应在工信部系统查询备案：<https://beian.miit.gov.cn/>。
