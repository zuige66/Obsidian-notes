这份教程适用于第一次使用 Linux 云服务器，目标是安全登录服务器、检查域名和备案情况，并为微信小程序准备一个图片安全检测接口。

> 重要：不要在聊天、截图或公开仓库中暴露服务器密码。此前已经出现在截图中的密码应视为已经泄露。若服务器由多人共用，不要擅自修改 root 密码，以免其他人无法登录；后续应创建自己的普通用户。

## 一、是不是使用 PuTTY？

可以使用 PuTTY，但不是必须。Windows 10/11 通常已经自带 SSH，直接在 PowerShell 中登录更方便。

推荐顺序：

1. 优先使用 Windows PowerShell 的 `ssh` 命令。
2. 如果系统没有 `ssh`，或者喜欢图形界面，再使用 PuTTY。

## 二、登录前需要准备的信息

需要确认以下内容：

- 服务器公网 IP
- SSH 端口，默认是 `22`
- 登录用户名，目前是 `root`
- 登录密码或 SSH 私钥
- 操作系统通常是 Ubuntu、Debian、CentOS 等 Linux 系统

密码只在登录窗口中输入，不要写进代码、Markdown 或 Git 仓库。

## 三、方法 A：使用 Windows PowerShell 登录（推荐）

打开 PowerShell，执行：

```powershell
ssh root@服务器公网IP
```

如果 SSH 不是默认的 22 端口：

```powershell
ssh -p 端口号 root@服务器公网IP
```

第一次连接时可能显示主机指纹，并询问：

```text
Are you sure you want to continue connecting (yes/no/[fingerprint])?
```

确认 IP 正确后输入：

```text
yes
```

随后输入密码。Linux 输入密码时屏幕不会显示星号或字符，这是正常现象，输入完成后按 Enter。

登录成功后，先执行只读命令了解服务器：

```bash
whoami
hostname
cat /etc/os-release
uname -a
df -h
free -h
```

退出服务器：

```bash
exit
```

## 四、方法 B：使用 PuTTY 登录

1. 从 PuTTY 官方网站下载安装 PuTTY。
2. 打开 PuTTY。
3. 在 `Host Name (or IP address)` 中填写服务器公网 IP。
4. `Port` 填 SSH 端口，通常为 `22`。
5. `Connection type` 选择 `SSH`。
6. 点击 `Open`。
7. 首次连接会出现服务器指纹提示，确认 IP 无误后接受。
8. 出现 `login as:` 时输入 `root`。
9. 输入密码并按 Enter。输入密码时不会显示字符，属于正常现象。

PuTTY 只是 SSH 登录工具，不是服务器本身。它与 PowerShell 的 `ssh` 本质上做的是同一件事。

## 五、登录后的安全检查

使用 root 时每条命令都拥有最高权限，输入命令前要认真检查。不要随意执行来源不明的脚本，也不要执行类似 `rm -rf` 的删除命令。

查看当前登录记录：

```bash
who
last -n 20
```

查看正在监听的端口：

```bash
ss -lntp
```

查看 Web 服务状态（哪个命令可用就看哪个）：

```bash
systemctl status nginx
systemctl status apache2
systemctl status httpd
```

查看 80 和 443 端口由谁占用：

```bash
ss -lntp | grep -E ':80|:443'
```

这些是只读检查，不会修改现有网站。

## 六、不要影响服务器上已有的网站

服务器的 80 端口已经部署了网站，因此不要停止、删除或覆盖现有 Nginx/Apache 配置。

建议让自己的后端服务只监听本机端口，例如：

```text
127.0.0.1:3001
```

然后由现有 Nginx 将一个独立子域名或路径转发到该端口，例如：

```text
https://api.example.com/image/check
```

推荐结构：

```text
微信小程序
    ↓ HTTPS
api.example.com
    ↓ Nginx 反向代理
127.0.0.1:3001
    ↓
图片安全检测服务
```

在没有备份并弄清楚现有配置前，不要直接修改 `/etc/nginx/nginx.conf`。通常应新增独立站点配置，并在修改前执行：

```bash
nginx -t
```

只有显示配置检查成功后才能重载：

```bash
systemctl reload nginx
```

注意：重载 Nginx 会影响服务器上的公共服务，操作前必须确认配置正确。

## 七、检查域名是否解析到服务器

在自己的 Windows PowerShell 中执行：

```powershell
nslookup 你的域名
```

如果返回的 IP 与服务器公网 IP 一致，说明域名解析到了这台服务器。如果提示找不到域名，或返回其他 IP，需要检查域名拼写和 DNS 解析。

用于小程序时，建议准备独立子域名，例如：

```text
api.example.com
```

然后给这个子域名添加一条 `A` 记录，指向服务器公网 IP。

## 八、检查 ICP 备案

打开工信部备案管理系统：

<https://beian.miit.gov.cn/>

进入 ICP 备案查询，输入根域名，例如：

```text
example.com
```

不要填写 `http://`、`https://`、路径或 `www`。查询结果中出现有效备案号、主办单位等信息，才说明该域名已经备案。

注意：

- 域名解析成功不等于已经备案。
- 网站可以通过 IP 打开，也不等于域名已经备案。
- 中国大陆服务器用于正式微信小程序接口时，通常需要有效备案域名。
- 小程序正式环境不能把裸 IP 当作合法请求域名。

## 九、微信小程序接口的基本要求

正式使用服务器接口一般需要：

1. 有效并可控制的域名。
2. 域名完成 ICP 备案。
3. 配置可信的 HTTPS 证书。
4. 在微信公众平台配置 `request`、`uploadFile` 等合法域名。
5. 服务端调用微信内容安全接口，不能只在小程序前端假装检测。

图片检测推荐流程：

```text
用户选择图片
    ↓
小程序上传到自己的 HTTPS 接口
    ↓
服务器调用微信图片内容安全检测
    ↓
通过：允许本地生成图纸
不通过：提示图片含违规内容
    ↓
服务器删除临时图片
```

不要长期保存用户上传的原图；只为安全检测短暂使用，并在检测完成后删除。

## 十、后续建议：创建独立普通用户

即使暂时使用 root，长期部署也建议创建独立用户，避免误操作整个服务器。示例仅供服务器所有者确认后执行：

```bash
adduser pindou
usermod -aG sudo pindou
```

之后可使用：

```powershell
ssh pindou@服务器公网IP
```

如果这是多人共用服务器，创建用户、调整防火墙、修改 SSH 配置或更改 root 密码前，应先确认不会影响现有使用者。

## 十一、第一次登录时推荐的操作顺序

1. 使用 PowerShell 或 PuTTY 登录。
2. 执行系统信息和磁盘检查命令。
3. 使用 `ss -lntp` 查看现有端口。
4. 查看 Nginx/Apache 状态，但先不要修改。
5. 在本机查询域名 DNS 和工信部备案。
6. 确认域名、备案、HTTPS条件满足后，再部署图片检测服务。
7. 后端先监听 `127.0.0.1:3001`，避免直接暴露端口。
8. 最后再配置 Nginx 子域名和微信小程序合法域名。

## 十二、常见问题

### 登录时密码没有显示，是不是键盘坏了？

不是。Linux SSH 输入密码时默认不显示任何内容，直接输入后按 Enter。

### PuTTY 和云服务器控制台有什么区别？

PuTTY 通过 SSH 远程登录；云服务器控制台由云厂商提供，通常还能管理重启、安全组、快照等资源。

### 能不能直接使用服务器 IP 给小程序调用？

开发测试时可能能临时绕过域名校验，但正式发布通常不行，需要已备案的 HTTPS 域名。

### 可以直接占用 80 端口吗？

不建议。80 端口已有网站，应让自己的程序监听其他本地端口，再通过 Nginx 反向代理。

### 可以一直使用 root 吗？

技术上可以，但风险较高。root 的误操作会影响整台服务器，正式部署更适合使用独立普通用户。
