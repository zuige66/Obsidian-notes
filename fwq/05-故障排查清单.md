# 05：故障排查清单

原则：先观察再修改，一次只改一件事，修改前备份，修改后验证。

## SSH 密码被拒绝

`Permission denied, please try again.` 表示 SSH 端口可达但账号验证失败。按 `Ctrl+C` 停止连续尝试，再确认账号、密码、端口以及是否允许 root 密码登录。若有云厂商控制台权限，优先用控制台终端检查或重置密码。

需要更详细的客户端日志时：

```powershell
ssh -vvv root@104.168.22.222
```

## 域名打不开

```powershell
nslookup dentrobot.com
curl.exe -I http://dentrobot.com
curl.exe -I https://dentrobot.com
```

先确认 DNS 指向正确 IP，再检查 80、443 端口。

## 服务器端逐层检查

```bash
uptime
df -h
free -h
ss -lntp
systemctl status nginx
journalctl -u nginx -n 100 --no-pager
```

## 常见 HTTP 状态

| 状态 | 检查方向 |
| --- | --- |
| `200` | 请求成功 |
| `301/302` | 检查跳转目标 |
| `403` | 检查权限或访问规则 |
| `404` | 检查路径和路由 |
| `500` | 查看应用日志 |
| `502` | 检查后端程序和代理端口 |
| `504` | 检查后端卡死或超时 |

求助时可以提供命令、完整报错、系统版本、服务状态和最近日志；必须遮住密码、私钥、API Key、Cookie、数据库密码和令牌。
