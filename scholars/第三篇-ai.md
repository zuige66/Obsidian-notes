## 题目：
学习运营考虑车网互动的电动汽车充电站
*Learning to Operate an Electric Vehicle Charging Station Considering Vehicle-Grid Integration*

- **作者**：Zuzhao Ye, Yuanqi Gao, Nanpeng Yu（美国加州大学河滨分校 UC Riverside 电气与计算机工程系）
- **期刊**：IEEE Transactions on Smart Grid, vol.13, no.4, pp.3038–3048（2022 年）
- **DOI**：10.1109/TSG.2022.3165479（arXiv:2111.01294v2，2022-08，作者接受稿）
- **源文件**：`D:/workplace/vehicle to grid/Learning to operate an EV charging station considering vehicle-grid integration.pdf`（12 页）
- **一句话结论**：**CADE 框架（集中分配 + 分散执行）**运营充电站——中央优化模块用学到的 Q 值把 EV 分配到充电桩/等待位，每个充电桩是一个独立 DQN 智能体决定充/放电功率、共享回放池和 Q 网络；利润超过 MPC 与贪心基准（仅次于全知信息的 MPC-ideal），单步计算时间随桩数**线性**增长（100 桩 1.7ms vs MPC 483~935 秒），且 Q 值可视化显示策略真的学会了「谷时充、峰时放」。

---

## 摘要
- **目的**：最大化充电站利润 $Z = B - C_p - C_l$（充放电净收入 − 未满足充电需求的惩罚 − 需量电费），同时考虑**等待区**、**V2G 双向充放电**、**需量电费（demand charge）**三类此前文献很少同时处理的现实要素
- **方法**：CADE 框架。集中分配：以学到的动作价值 Q 为系数解一个小型 0-1 优化，决定哪些 EV 上桩、哪些进等待区；分散执行：每个充电桩 = 一个 DQN 智能体，各自决定本桩充/放电功率，经验存入**共享回放池**，同构桩共享同一套 Q 网络参数并周期性广播
- **创新点**：
  1. 首个同时考虑等待区、车网互动（VGI）、需量电费的充电站 RL 运营框架（前人要么没等待区、要么单向充电、要么忽略需量电费）
  2. 用「每桩一个智能体」化解**状态/动作空间维度随 EV 随机到达/离开而变化**的难题；共享回放池大幅提升样本效率（约 1000 episodes 收敛，远低于综述平均 7000）
  3. 设计在线算法把全站级需量电费惩罚**分摊**到各桩的个体奖励里
- **结果（具体数字）**：
  - 利润对比（30 条随机轨迹 × 4 种到达模式平均）：CADE > MPC(1h预测) > MPC(2h) ≈ GRD > GRD-noVGI，仅低于拥有完美 2 小时未来信息的 MPC-ideal（不公平基准）
  - 可扩展性：桩数 10→100（等待位=Nc/2），**单桩日均利润稳定在 $7.8~8.4**；单步计算 0.7ms→1.7ms（线性），MPC(1h) 3s→483s、MPC(2h) 19s→935s（爆炸）
  - 训练 ~1000 episodes 后利润稳定；未满足惩罚 $C_p$ 收敛到 0；需量电费 $C_l$ 下降有限（作者承认：未来需求难预测）
- **结论/贡献/意义**：RL + 优化的混合架构兼顾可扩展性与可解释性；对充电站运营商，「智能充电桩」在经济上成立的证据

## 前言
- **背景**：
  - EV 市场十年指数增长 → 需要既能满足充电需求又划算的智能充电站
  - 模型法路线已很丰富：Lyapunov 优化做定价+调度、MIP+对偶/Benders 分解、两阶段随机规划、联盟博弈削配网冲击等——共同点：依赖精细的定制模型，规模一大求解就慢
- **需要解决的问题**：站内多 EV 协调调度的状态空间、动作空间**维度随车辆随机到达/离开而变化**，传统 RL 建模（把全站状态拼成向量）无法直接处理
- **已有/前人研究不足之处**：
  1. 两阶段启发式 RL（先学车队聚合策略、再用简单启发式翻译到单车）——启发式不保证最优
  2. 用手工设计的特征函数线性组合表示状态动作函数——特征工程困难
  3. 网格表示法让状态维度恒定——但动作只能「满功率充/不充」二选一，没有中间功率
  4. 用 RL 预测未来条件、再由模型法定功率——预测很难准
- **本文开展了什么研究（创新点）**：CADE 框架 = 集中分配（优化）+ 分散执行（每桩 DQN）+ 共享回放池；问题建模涵盖等待区、VGI、需量电费

---

## 框架
- **方法**：
  - 集中分配：0-1 优化（式 18-19b），目标 = 最大化「EV k 上桩的价值 $q_k^c=\max_a Q(s,a)$ + 进等待区的价值 $q_k^w=Q(s,a{=}0)$」之和，约束充电桩数上限
  - 分散执行：每桩 DQN（式 17 损失 + 目标网络 + ε-greedy），Q 网络输入 (s,a) 输出标量 Q（动作是有序变量，此结构合适）
- **因素**：状态 9 元素 = {是否有车连接, 全局时间, 剩余停留时间, 当前电量, 剩余需求电量, 等待区 EV 数, 等待区剩余电量总和, 分时时段 one-hot, 本时段历史最大负荷}
- **评价指标**：充电站日均利润（30 条测试轨迹 × 4 种到达模式）；单步计算时间（可扩展性）
- **案例对象**：EV 到达服从 Poisson 过程，4 种真实到达模式（办公区/居民区/高速/零售，高速有多个峰、零售有午峰+晚峰）；基准站 10 桩 + 5 等待位；规模实验 Nc ∈ {10, 20, 50, 100}

---

## 收获
- **论点（结论）**：
  1. 「**等待位 = 功率为 0 的虚拟充电桩**」的等价变换，让「分配哪辆车上桩」和「桩用什么功率」统一成一个 Q 值比较问题——维度可变问题被架构层面的分解化解
  2. 同构桩**共享一套 Q 网络参数 + 共享回放池**：每个桩每步都产生训练样本，等效批量经验 → ~1000 episodes 收敛（第一篇综述说领域平均要 7000）
  3. 学到的策略可解释：Q 值分析显示——峰时偏好放电、谷时偏好充电；EV 快离开（剩余时间→0）偏好大功率；等待区车多时偏好大功率；**历史最大负荷已很高时反而不在乎需量电费**（棘轮效应：本时段记录已经刷高，再加负荷不增加边际需量费）
- **论据**：
  - 奖励三分量与利润三组件一一对应（$r = r_b + r_p + r_l$），全站级成本通过分摊算法落到桩级
  - 需量电费在线分摊（Algorithm 1）：仅当全站总功率超过历史峰值时产生增量成本 $R_l^t$，按各桩功率占比 $a_j/\sum_j a_j$ 分摊（功率大的多担）
  - 等待区未完成惩罚按 $(a_{max}-a_j)$ 权重反向分摊（功率越低罚越重）→ 激励各桩加大功率
  - 经济设定合理：放电补偿价 $p_d$ > 充电服务价 $p_c$，覆盖电池退化成本

---

## 存疑
- 惩罚系数 φ=1 $/kWh 固定，无敏感性分析；$C_l$ 训练中下降有限——需量电费这块优化其实不成功
- 全部基于 Poisson 仿真到达，**无真实充电数据验证**（综述挑战 1「全是仿真」在本文同样成立）
- 假设桩同构、EV 在等待位/充电位之间切换时间可忽略；用户会如实申报离开时间和目标电量
- MPC 基准只用 1h/2h 预测窗，更长预测窗的 MPC 可能更强；且 MPC 求解时间随规模爆炸某种程度上是 MIP 实现问题
- 与第二篇对照：本文动作是**离散化**充电功率（间隔 Δa），综述指出离散化损失精度——作者选 DQN+离散动作换来的是稳定与简单，是权衡而非最优

# 精读细节（分层笔记 · 第二层）

## 1. 利润模型：三组件（第 II 节）
$$Z = B - C_p - C_l$$

**等号左边**：$Z$ = 充电站在时间窗 $T$ 内的运营利润（优化目标，越大越好）。

**等号右边逐项拆解（1 正 2 负）**：

| 项 | 符号方向 | 含义与直觉 |
|---|---|---|
| $B$ 充放电净收入 | **正**（赚钱） | 卖充电服务 + 峰时卖电给电网的总收入，见下面 $m_t$ 拆解 |
| $C_p$ 未满足惩罚 | **负**（赔钱） | 车走时没充到目标电量的补偿金——服务违约成本 |
| $C_l$ 需量电费 | **负**（赔钱） | 按计费周期内**最大负荷**（kW）计费的电费部分，与按电量计费的能量电费相对；削峰不够就要交这笔钱 |

**$B$ 的内部结构**（式 2-3）：$B=\sum_{i}\sum_{t} m_t|a_{it}|\Delta t$，其中单位净收入分两种情况：
$$m_t=\begin{cases}p_t^c-p_t^e & a_{it}\ge 0\ (\text{充电：向车主收 } p^c,\ \text{向电网买电付 } p^e,\ \text{赚差价})\\ p_t^e-p_t^d & a_{it}<0\ (\text{放电：把车上的电以 } p^e \text{ 卖给电网},\ \text{再补偿车主 } p^d)\end{cases}$$
- 符号方向：谷时 $p^e$ 低 → 充电差价大 → 该充电；峰时 $p^e$ 高到 $p^e>p^d$ → 放电有得赚 → 该放电——**分时电价结构本身就指明了策略方向**
- **$p^d > p^c$**（放电补偿价高于充电服务价）：覆盖车主电池退化成本，否则没人愿意被放电

**$C_p$ 的内部结构**（式 4）：$c_p^i=\phi\,(e_{tgt}^i-e_{fin}^i)^+$，上标 $+$ 表示 $\max(\cdot,0)$——只有最终电量**低于**目标才罚，充过头不罚；差距越大罚越多

**$C_l$ 的内部结构**（式 8-9）：$C_l=\frac{T}{T_B}\sum_{h}p_h^l L_h^+$，$L_h$ = 分时段 $h$ 内记录的站级最大负荷；这是大多数文献忽略的成本项，因为优化它需要**预知未来峰值**，极难——也正因如此本文才把它的分摊做进 RL 奖励（见第 5 节）

## 2. MIP 形式与约束分类（式 10-11g）
- 若全知未来所有 EV 的到达/离开/需求 → 混合整数规划（MIP）可解全局最优（oracle）
- 约束三组：**功率**（上下限 a_min/a_max；未连接桩功率为 0）、**空间**（同时上桩数 ≤ Nc；在站车辆数 = 上桩 + 等待；不在站不能上桩）、**能量**（电池电量 ∈ [e_min, e_max]）

## 3. CADE 框架总览（Fig. 1）
三步循环：①EV 随机到达 → ②集中分配（充电站级，优化）→ ③分散执行（桩级，RL）。训练期共享回放池 + 周期广播 Q 网络；部署期只保留「观测状态 → argmax Q → 输出功率」，毫秒级响应

## 4. 桩级 MDP（第 III-B 节）
| 要素 | 设计 |
|---|---|
| 状态 $s_t^j$ | {连接位, 时间 t, 剩余停留 $t_r$, 当前电量 $e$, 剩余需求 $e_r$, 等待区车数 $N_{EV,w}$, 等待区总剩余电量 $E_r^w$, ToU one-hot $\tilde h_t$, 本时段历史峰值 $L_h^t$} |
| 动作 $a_t^j$ | 离散充电功率，可行区间 $[\max(a_{min},\frac{e_{min}-e}{\Delta t}),\ \min(a_{max},\frac{e_{max}-e}{\Delta t})]$ 均匀离散化 |
| 奖励 | $r = r_b + r_p + r_l$（下节） |
| 桩级状态的关键设计 | 把**等待区聚合量**（车数、总剩余电量）放进桩的状态——单个桩「看见」全站拥堵程度 |

**动作区间上下界逐项拆解**：$a^{upper}=\min\big(a_{max},\ \frac{e_{max}-e}{\Delta t}\big)$，$a^{lower}=\max\big(a_{min},\ \frac{e_{min}-e}{\Delta t}\big)$
- 上界取小：物理最大功率 vs「一个时间步就把电池充满」所需的功率——快充满了就自动收窄，不许过充
- 下界取大：物理最大放电功率（负值）vs「一个时间步就把电池放到下限」的功率——电量约束同样自动生效
- 区间随当前电量 $e$ **动态收缩**：非法动作从源头裁掉，不靠奖励惩罚事后补救（对比第二篇的惩罚式约束处理，两条路线）

## 5. 奖励设计：两个方向的分摊（式 14-16）
$$r_t^j = r_b^j + r_p^j + r_l^j$$

**桩级奖励与站级利润严格同构**：$r_b$ 翻译净收入 $B$（正贡献），$r_p$ 翻译未满足惩罚 $C_p$（负贡献），$r_l$ 翻译需量电费 $C_l$（负贡献）——每个桩的奖励就是「这家站利润公式」投影到自己身上的一份。

- $r_b = m_t|a|\Delta t$：即时净收入
- $r_p = -(c_p + c_{p,w})$：本桩 EV 离开未达标罚（式 14，$t_r=0$ 时结算）+ 等待区罚分摊。分摊权重 $\frac{a_{max}-a_j}{\sum_j(a_{max}-a_j)}$——**功率越低罚越重**（鞭策慢桩）
- $r_l$：需量电费增量分摊。Algorithm 1：全站总功率 $\sum_j a_j$ 超过历史峰值 $L_h^t$ 时，增量成本 $R_l^t = \frac{T}{T_B}p_h^l(\sum a - L_h)$，按 $a_j/\sum a$ 分摊——**功率越大罚越重**
- ⚠️ 注意两种分摊方向相反：未完成惩罚要「催」，需量惩罚要「省」——各自服务于不同的利润组件，设计很精细

## 6. 集中分配模块（第 III-D 节）
- 第 k 辆车上桩创造价值 $q_k^c = \max_a Q(s(k{=}1), a)$；进等待区价值 $q_k^w = Q(s(k{=}1), a{=}0)$（等价于接一个 0 功率虚拟桩）
- 分配优化逐项拆解（式 18-19b）：
  $$\max_{\lambda_k\in\{0,1\}}\ \sum_{k=1}^{N_{EV}}\big[\lambda_k\, q_k^c+(1-\lambda_k)\,q_k^w\big]\qquad \text{s.t.}\ \sum_k \lambda_k\le\min(N^c,N_{EV})$$
  - $\lambda_k$：第 k 辆车是否上桩（1=上桩，0=进等待区）——唯一的决策变量
  - $q_k^c=\max_a Q(s_k,a)$：这辆车上桩后能拿到的最优 Q 值；$q_k^w=Q(s_k,a{=}0)$：它在等待区（等价于接 0 功率虚拟桩）的 Q 值——**等待也被赋了价值**，两种选择可以直接比大小
  - 目标 = 全站价值总和最大；约束 = 上桩数不超过充电桩总数。变量只有 $N_{EV}$ 个 0-1 变量，毫秒级可解
- 用的 Q 是上一时间步学到的 → **优化和 RL 各干各的擅长事**（优化处理硬约束，RL 处理随机性）

## 术语表
- **CADE（Centralized Allocation and Decentralized Execution，集中分配与分散执行）**：本文框架；优化管分配、RL 管功率
- **VGI（Vehicle-Grid Integration，车网互动）**：充电站与电网双向能量交换（含 V2G 放电）
- **Demand charge（需量电费）**：按计费周期内最大负荷（kW）计费的电费部分，与按电量（kWh）计费的能量电费相对
- **MPC（Model Predictive Control，模型预测控制）**：滚动预测 + 滚动优化；依赖预测精度
- **MPC-ideal / oracle**：拥有完美未来信息的基准（不公平上界）；**GRD**：按紧迫度 $e_r/t_r$ 排序的贪心分配基准
- **ToU（Time-of-Use，分时电价）**；**棘轮效应**：峰值记录已刷高后，继续加负荷不增加边际需量费
- **DQN**：价值型深度 RL，见第一篇综述术语表

## 可借鉴点（结合车网互动场景）
1. **「维度可变状态空间」的三种解法之一**：每桩一 agent + 全站聚合特征进状态（另两种：第四篇的聚合分箱状态、第五篇的聚合商+一致性分配）——大创做多桩调度时按场景三选一
2. **共享回放池/共享参数**是同构智能体提效的标准手段，样本效率直接体现在收敛速度（1000 vs 7000 episodes）
3. **约束→奖励的「分摊」思路**：第二篇用乘性惩罚，本文把全站级成本按权重摊到个体奖励——两种工程解法可对照使用
4. **Q 值可视化解释**是论文加分项：逐分量扰动状态、展示策略逻辑，审稿人友好；写大创结题报告可直接借用这个分析套路
5. **成本模型模板**：充放电价 + 需量电费 + 退化补偿（$p_d>p_c$）三件套，做充电站运营/定价研究时比「只有能量成本」的简化模型更扎实
6. 与第一篇综述的连接：本文正是综述说的「两阶段方案」（集中再分配 + 分散功率控制，共享 Q 网络与回放池）的代表文献；填补「运营+电网双立场」空白
