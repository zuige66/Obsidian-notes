*Reinforcement learning for electric vehicle charging scheduling: A systematic review*

- **作者**：Zhonghao Zhao, Carman K.M. Lee（通讯）, Xiaoyuan Yan, Haonan Wang（香港理工大学工业与系统工程系 + 人工智能设计实验室 LiAID）

## 摘要
- **目的**：系统综述用强化学习（RL，MDP 建模）求解 EV 充电调度问题（CSP）的现有研究——总结 CSP 与 RL 算法现状、分析已有文献、讨论当前挑战、识别未来方向
- **方法**：系统性文献综述（SLR）。Web of Science + IEEE Xplore + ScienceDirect 布尔检索（2017-01 ~ 2023-12），755 → 384（去重）→ 151（题目摘要筛查）→ **111 篇**（全文精读）纳入分析；从**调度目标、状态空间、动作空间、RL 算法、训练策略**五个维度归类讨论
- **创新点**：
  1. 首篇针对「RL 用于 EV 充电调度」的系统综述（此前无同类综述）
  2. 基于描述性分析的出版趋势统计
  3. 五视角文献分析框架（目标/状态/动作/算法/训练策略）
  4. 提出 4 步 RL 算法选型流程 + 挑战与方向总结
- **结果（具体数字）**：
  - 调度方法：间接法 78/111（**70.3%**）；直接法 38/111（34.1%，其中直接控制 17/38、充电站推荐 11/38；一文多法故总和 >111）
  - 立场：EV 用户 58/111（**52.3%**，主目标降充电成本 42/58=72.4%）；EV-电网互动 46/111（41.4%，主目标削峰 PLR 36/46=**78.3%**）；充电站运营 34/111（30.6%，利润 22/34、运营成本 10/34）；2022 年后发表的论文中电网视角占 39/72（54.2%）——**电网侧反超用户侧**
  - 算法：DQN 34/111（30.6%）、DDPG 25/111（22.5%）、SAC 17/111（15.3%）；SARSA 仅 2 篇；离线 RL 仅 4 篇（3.6%，全为 FQI）；多智能体 22 篇（19.8%）
  - 动作空间连续的占 64/111（57.7%）；平均训练时长约 **7000 episodes**（41/111 篇定义 1 episode = 1 个或多个营业日）
- **结论/贡献/意义**：CSP 是高维带约束优化问题，传统精确算法/启发式难以胜任；MDP 形式的 RL 是有前景的控制范式；2020 年起发文量跃升并保持稳定；但现有研究全部基于仿真验证、场景偏简单（多为单一立场），离实际部署仍有距离

## 前言
- **背景**：
  - 2022 年全球 EV 销量约 1000 万辆、占新车销量 14%+（IEA）；各国以补贴、排放标准、充电基建投资推动普及
  - 阻碍大规模普及的四大痛点：充电设施不足、电网过载、充电时间长、续航焦虑
  - 解锁 EV 灵活性的关键手段 = 充电调度：优化「**何时、何地、如何**充电」，同时考虑电价、电网负荷、车辆需求等动态因素
- **需要解决的问题**：CSP 决策空间高维、动态、不确定，传统方法（精确算法/人工启发式/近似算法）性能随问题规模骤降，且依赖精确环境模型
- **已有/前人研究不足之处**：
  1. 多数 CSP 是 NP-hard，现有算法难以处理高维决策空间
  2. 传统方法都是 model-based，需要精确数学模型——真实场景中 EV 用户充电行为受个人偏好、心理、城市发展甚至天气影响，无法用单一模型描述
  3. 传统方法基于静态确定性假设，无法捕捉动态不确定的充电环境，新实例需重调/重解
  4. 「据我们所知，此前没有研究系统综述 RL 用于 EV 充电调度」（本文定位）
- **本文开展了什么研究（创新点）**：首篇该方向的系统综述 + 出版趋势分析 + 五视角文献讨论 + 挑战与未来方向

## 收获
- **论点（结论）**：
  1. RL 优于传统方法的四条理由：①CSP 天然可表述为离散时域 MDP；②能克服大状态-动作空间（GPU 加速训练）；③无需人工特征工程与领域技巧，通用性强；④model-free，不依赖环境先验知识
  2. 算法选型有迹可循：**四步流程**——单/多智能体 → RL/DRL（看网络规模）→ 在线/离线（看能否交互）→ 具体算法（离散动作选 DQN 系；连续动作选 DDPG/SAC，RL 背景强选 DDPG、否则选结构相对简单的 SAC）
  3. 领域现状画像：DQN 最流行但只适合离散动作；连续动作（充电功率/充电价，恰好是 CSP 最常用的动作变量）上 DDPG/SAC 优于离散化 DQN；离线 RL 和多智能体 RL 严重欠开发
- **论据**：
  - 状态空间统计：SoC 和电价是跨立场的最大公约数（用户视角 SoC 79.3% / 电价 43.1%；运营视角电价 52.9% / 需求 44.1% / SoC 44.1%）
  - 动作空间统计：充电速率是第一动作；运营视角第二是充电价（38.2%），电网视角第二是直接控制（充/放/不动，28.3%）
  - 离线 RL 实例：Chisè et al. 用 ISO New England 672 天充电数据训练 FQI；Sadeghianpourhamami et al. 用 10 个充电站一年真实数据，且学到的策略可**免重训练**迁移到更多站点——离线 RL 可行性的直接证据

- 统计口径陷阱：间接法 78 + 直接法 38 = 116 > 111（一文多法），比例基数不同，引用时须注明
- 算法流行度 ≠ 算法优劣：DQN 使用最多（30.6%）只反映门槛低，综述自己承认离散化 DQN 会损失控制精度、策略次优
- 检索截止 2023-12：离线 DRL（BCQ/CQL）、联邦 RL、安全 RL 等 2023 年后热点覆盖极浅（附录仅零星几篇）；**第二篇用的 TD3 完全不在其算法统计主列表中**，引用综述结论时注意时效

# 精读细节（分层笔记 · 第二层）

## 1. CSP 问题定义与三个立场（第 2.1 节）
- 形式化：设决策变量 $X$、目标函数 $f$，CSP 即在交通网络上寻找最优跨期调度序列 $X_i^*(t),\ t\in\{1,\dots,T\}$——充电需求可被转移到**其他时段或其他充电站**
- 三个立场（standpoint）：
  | 立场 | 核心指标/目标 |
  |---|---|
  | EV 用户 | 服务质量：等待时间、续航焦虑、充电成本 |
  | EVCS 运营 | 收入最大化/成本最小化：基建+设备+电价成本 与 充电桩利用率 的平衡 |
  | EV-电网互动 | 安全并网：削峰（PLR）、负荷转移 |
- **重要 gap**：绝大多数文献只从单一立场建模，少数考虑两个立场，**没有任何研究同时覆盖三个立场**（真实充电网络运行天然涉及三方）

> **补注｜PLR 是什么，以及「削峰」和「负荷转移」不是一回事**
> - **PLR = Peak-Load Reduction（峰值负荷削减）**，原文 3.2.3 节直接用这个缩写统计目标。它衡量的是**尖峰被压下去多少**（常用峰值功率降幅 % 或峰谷差缩小量），是**结果指标**。
> - **负荷转移（load shifting）/ 填谷（valley filling）**是**手段**：把同一批电量从峰时段挪到谷时段。削峰往往伴随填谷，但两者可分别度量——只削峰不填谷，总电量不变、曲线更尖；只填谷不削峰，峰值没动。
> - 所以「36/46 篇电网立场论文以 PLR 为目标」的意思是：这些研究真正在乎的是**别让配变/线路在晚高峰过载**，而不是省电费。做自己的题时若目标写成「降负荷方差」，就与这 36 篇不在同一口径上，引用时要说明。
> - 三个立场一句话记法：用户看**等待时间/成本/续航焦虑**，运营商看**利润/桩利用率**，电网看**峰值/波动/电压**。

## 2. 直接法 vs 间接法（Fig. 3）
- **直接法**（38/111）：用户自愿参与调度方案，决策者有权**拒绝**部分充电请求。两类：直接控制（给到站司机「充电/放电/不动」选项）、充电站推荐（在线平台指示何时去哪充）
- **间接法**（78/111，70.3%）：动态调整充电相关参数引导需求——**调充电价**（时变电价劝退价格敏感用户）或**调充电功率**（拉长/缩短充电时间控制时段负荷）
- 间接法更难实现但**对用户更可接受**，所以占主流——这与第二篇（动态定价）的动机完全一致

## 3. 传统方法的三条根本局限（第 2.1 节）
1. CSP 多为 **NP-hard**，高维决策空间使现有算法性能随规模骤降
2. 精确/启发式/近似算法全是 **model-based**，需要精确环境模型；而充电行为受偏好、心理、城市水平、天气影响，难以单模型描述
3. 假设**静态确定性系统**，无法捕捉动态不确定性；真实环境频繁变化需反复重解

## 4. MDP 五要素在 CSP 中的实例化（第 2.2.1 节）
| 要素 | 定义 | CSP 对应 |
|---|---|---|
| S 状态 | 做决策所需的全部系统信息（$s_t$ 仅依赖 $s_{t-1}$） | 电量 SoC、充电桩空闲状态、电价、充电时间 |
| A 动作 | 可用的调度决策集合（受预设约束限制） | 充电价格、充电功率、充/放/不动、充电站推荐 |
| R 奖励 | 状态转移上的标量信号；累计奖励 = 优化目标 | 约束问题中不可行动作可置 0 惩罚 |
| P 策略 | $\pi(a_t\mid s_t;\theta)$，状态→动作映射；确定性/随机性 | — |
| H 地平线 | $s_0$ 到 $s_T$ 的离散时间步（episode） | 一个调度日/营业日 |

> **补注｜「马尔可夫」到底约束了什么，以及 P 为什么有两个意思**
> - **马尔可夫性**：$s_t$ 已包含做决策所需的**全部历史信息**，因此 $P(s_{t+1}\mid s_t,a_t)$ 不必再回头看 $s_{t-1}$。工程含义很硬：**状态里必须塞进「记忆」**。反例——只放当前电价而不放「今日已充多少电量」，就不满足马尔可夫性，策略会重复做同一个决定；第三篇把「本时段历史最大负荷 $L_h$」放进状态，正是为了让需量电费（依赖历史峰值）变得马尔可夫。
> - **符号复用提醒**：这张表里 **P = 策略（policy）**，而第 5 节转移概率 $P(s'\mid s,a)$ 里 **P = probability**。两个 P 不是一回事，原文靠上下文区分，读公式时要留意。
> - **地平线 H**：一个 episode 的最大步数，CSP 里通常取 24（一个调度日，每小时一步）。H 同时决定两件事——「策略能前瞻多远」和「折扣回报实际累加多长」（$H=24$、$\gamma=0.99$ 时，最后一步的权重约 $0.99^{24}\approx0.79$，基本不打折；这也是第三篇敢取 $\gamma=1$ 的背景）。
> - 表里 R 那一行的「不可行动作置 0 惩罚」是**最朴素的约束处理**，代价见第 14 节挑战 5（奖励变稀疏 / reward hacking）。

## 5. 在线 RL（第 2.2.2 节）
- 按回合顺序模拟、边交互边更新（区别于离线 RL 一次性更新全部回合）

> **补注｜model-free、on-policy、off-policy、自举——后面所有算法都要先过这四关**
> - **model-based vs model-free**：前者需要知道（或先学出）环境怎么变，即 $P(s'\mid s,a)$ 和奖励函数；后者不要模型，只靠「试了看结果」。「无需预知充电行为模型」是本文反复强调的卖点，也是第二篇（不建需求模型）、第四篇（只吃历史数据）的共同底气。
> - **on-policy**：拿**当前策略**去采样、再去评价**这个策略本身**（SARSA、REINFORCE、PPO、第五篇）。策略一更新，旧数据立刻「过期」，只能丢——样本效率低，但优化目标始终对准自己，稳定。
> - **off-policy**：数据可以来自任意旧策略（Q-learning、DQN、DDPG、TD3、SAC、第二篇），所以能把转移存进**经验回放池**反复榨，样本效率高；代价是「学到的目标」与「实际采数据的行为」不一致，容易**高估**——这正是 DQN 的病根，也是第二篇用「双 Q 取小」来治的东西。
> - **自举（bootstrapping）**：用**自己当前的估计**当更新目标（TD 里 $R_{t+1}+\gamma V(s')$ 的 $V(s')$ 就是自己算的）。好处是不用等回合结束就能学；坏处是估偏了会自我放大——目标网络、软更新、延迟更新都是为压这个风险而生。
> - 记法：**on/off 说的是「数据归谁」，model-free 说的是「要不要环境公式」，自举说的是「目标从哪来」**。三个维度互相独立，别混成一个。
- **价值方法**——先看懂 TD 递推这一条，其余都是它的变体：
  - TD 学习递推（式 3）：$V(s_t)\leftarrow V(s_t)+\alpha\big[\underbrace{R_{t+1}+\gamma V(s')}_{\text{新证据}}-\underbrace{V(s_t)}_{\text{旧估计}}\big]$
    - 方括号 = **TD 误差**：新证据（拿到的即时奖励 $R_{t+1}$ + 下一状态的价值估计 $\gamma V(s')$）与旧估计 $V(s_t)$ 的差——估计偏了就往回修
    - $\alpha$（学习率）：每次修正多大一步；$\gamma$（折扣因子）：未来的价值打几折（贴现）
    - 直觉：不需要等整个回合结束，每走一步就用「一步的真实奖励」校准一次估计
  - **SARSA**（on-policy，式 4）：把 $V$ 换成 $Q$，新证据里用**实际执行的**下一个动作 $a'$：$Q(s_t,a_t)\leftarrow Q(s_t,a_t)+\alpha[R_{t+1}+\gamma Q(s',a')-Q(s_t,a_t)]$——评价的是「我正打算执行的策略」，边探索边学
  - **Q-learning**（off-policy，式 5）：$Q(s_t,a_t)\leftarrow Q(s_t,a_t)+\alpha[R_{t+1}+\gamma\max_{a'}Q(s',a')-Q(s_t,a_t)]$
    - 与 SARSA 唯一区别：$\max_{a'}$——假设下一步走**最优**动作，不管实际探索时走了哪步 → 直接逼近最优策略（行为策略与学习目标分离，故名 off-policy）
- **策略方法**：
  - REINFORCE 策略梯度逐项拆解（式 6）：$\nabla J(\theta)=\mathbb{E}\big[\sum_t \nabla\log\pi(a_t|s_t;\theta)\cdot\gamma^{t-1}R_t\big]$
    - $\nabla\log\pi(a_t|s_t;\theta)$：动作对数似然的梯度——指向「让刚做的这个动作概率变大」的方向
    - $\gamma^{t-1}R_t$：折扣回报，给上面的方向**加权**——结局好（R 大）就大幅调高该动作概率，结局差就调低
    - 一句话直觉：**「照抄成功经验、避开失败动作」的数学化**；$\mathbb{E}[\cdot]$ = 对整条随机轨迹取平均
  - 痛点：整条轨迹采样、奖励高方差 → 训练慢；CSP 硬约束下多数采样轨迹低质甚至无意义
  - 改进：减 baseline $l(s_t)$ 降方差不引入偏差（式 7-8）

## 6. 离线 RL（第 2.2.3 节）
- 从**静态转移数据集**学习，不与真实环境交互——适合「在线采样昂贵/有安全顾虑」的场景；EV 充电网络有不少公开数据集可用
- 代表算法 **Fitted Q-iteration（FQI）**：对整个转移经验集反复做 Bellman 回归迭代（Algorithm 2），数据集只提供完全可观的问题实例、由仿真轨迹估计策略
- 挑战：与 Q-learning 一样受维度灾难困扰（采样效率低）

## 7. 多智能体 RL（第 2.2.4 节）
- 适用：多个理性 agent 共存于共享环境（EV 用户、充电站、电网各自独立决策）；框架 = **马尔可夫博弈**，六元组 $\langle \mathcal{M},\mathcal{S},\mathcal{A}^i,\mathcal{R}^i,\mathcal{P},\mathcal{H}\rangle$
- **纳什均衡（式 10）逐项拆解**：$v_i(s,\pi^*)\ge v_i(s,\pi_i,\pi^*_{-i})$
  - 左边 $v_i(s,\pi^*)$：所有人都按均衡策略组合 $\pi^*$ 行动时，agent $i$ 拿到的价值
  - 右边 $v_i(s,\pi_i,\pi^*_{-i})$：**只有我**偷偷换成任意别的策略 $\pi_i$、其余所有人（下标 $-i$）保持不变时的价值
  - 不等式含义：单方面背叛占不到便宜——均衡 = 「没有任何人有动机先变」，多智能体版的「最优」
- **Nash Q-learning**：把博弈论嵌入 Q-learning，$Q_i$ 按所有 agent 联合动作计算，迭代收敛到 Nash Q 值（式 11-12）
- CSP 中多为**竞争**场景（充电站抢利润 vs 电网要削峰）；有外部约束时也可合作

> **补注｜马尔可夫博弈、下标 $-i$、平均场、CommNet**
> - **马尔可夫博弈**：MDP 的多人体版本——状态转移同时受**所有 agent 的联合动作**影响，奖励也升级成「每人一份」$R^i$。它是「多个充电站互相抢客、又共同影响电网」这类问题的标准建模框架。
> - **下标 $-i$（如 $\pi_{-i}$）**：除我以外的所有人。博弈论里所有均衡概念都是「我给定时，别人怎么做 / 别人给定时，我怎么着」——看到 $-i$ 一律读作「其余参与者」。
> - **平均场近似（mean field）**：$N$ 个 agent 两两交互共 $N^2$ 项，规模一大就爆。平均场把「每个 agent 和每个别人互动」换成「每个 agent 和**群体的平均效应**互动」，复杂度降到 $O(N)$。用在几十上百个充电站互相定价的场景（Qian 2021a：Q 值按邻近两两交互分解后取平均代替）。
> - **CommNet**：让多 agent 通过**可微通信信道**交换隐向量的网络结构——每个 agent 把自己的隐藏层输出广播出去、取平均后再继续前向，于是策略能学到「协作」而不仅是「各自为战」。
> - 与第三篇「共享参数 + 共享回放池」是两条不同的协作路线：**CommNet 靠通信（运行时交换信息），共享回放池靠共享经验（训练时交换数据）**。前者要求在线通信，后者不要求。

## 8. DRL（第 2.2.5 节）
- 动机：CSP 状态-动作表示复杂，传统 RL（查表）维度灾难；DNN 做函数逼近可自动学特征，免人工特征工程

> **补注｜「维度灾难」到底灾在哪，以及 actor / critic 谁是谁**
> - **维度灾难**：查表法要为**每一个**状态-动作对存一个格子。若状态有 $k$ 个维度、每维离散成 $m$ 档，格子数是 $m^k$——第二篇的状态是 $2N+1$ 维连续量，$m=100$ 时 5 个设施就已经是 $100^{11}$ 量级，**物理上存不下**。DNN 用固定参数量的函数去逼近这张巨表，才把问题变可行。
> - **actor（演员）**：策略网络 $\pi_\theta(a\mid s)$，负责「做动作」；**critic（评论家）**：价值网络 $Q_\phi(s,a)$，负责「给这个动作打分」。actor 自己不知道哪个动作好，它顺着 critic 的梯度 $\nabla_a Q(s,a)$ 往高分方向挪——**critic 的质量直接决定 actor 学对学错**。这就是第二篇 TD3「critic 每步更新、actor 隔一步更新」的原因：评分员还没学准，先别急着改动作。
> - 与纯策略梯度的区别：REINFORCE 用**整条轨迹的实际回报**当权重（无偏、方差极大），actor-critic 用 critic 的**估计值**当权重（方差小、但有偏）——「方差换偏差」的取舍贯穿全篇。
> - DQN 系只有 critic（Q 网络），动作靠 $\arg\max_a$ 现取——所以它天然做不了连续动作。这条就是第 12 节「离散动作→DQN、连续动作→DDPG/SAC」的根因。
- **价值系**：
  - **DQN** = Q-learning + DNN，三组件：Q 网络 + **经验回放**（降方差提效率）+ **目标网络**（固定频率更新、加速收敛）。损失函数逐项读（式 13）：
    $$L(\omega)=\mathbb{E}\big[\underbrace{R+\gamma\max_{a'}Q(s',a';\omega^-)}_{\text{目标值（暂时冻结）}}-\underbrace{Q(s,a;\omega)}_{\text{当前网络的预测}}\big]^2$$
    - 括号内 = TD 误差：目标值 = 即时奖励 + **目标网络**（参数 $\omega^-$，隔一段才从 $\omega$ 拷贝一次）估计的未来最优价值；预测 = 当前 Q 网络的输出
    - 平方 + 期望 = 把「TD 误差」变成可梯度下降的回归损失——本质是让网络拟合自举目标
    - 若目标值也用 $\omega$ 实时算，目标会跟着预测一起动（「追自己的尾巴」），训练不稳定——这就是目标网络存在的理由
  - 缺陷：取 max 导致 **Q 值过估计**、训练不稳、只能离散动作
  - **DDQN**：双网络分离「选动作」与「估 Q 值」去过估计；**D4QN**（Dueling DDQN）：把 Q 分解为状态价值 + 动作优势
- **策略梯度系**（多用 actor-critic 框架）：
  - **DDPG**：actor 学策略、critic 估 $Q$ 反馈；确定性策略直接输出**连续动作**免离散采样——适合充电功率/价格这类连续控制量；缺陷：样本效率低
  - **SAC**：**最大熵框架**。soft 价值函数逐项拆解（式 18）：$V(s)=\mathbb{E}\big[Q(s,a)-\alpha\log\pi(a|s)\big]$
    - $Q(s,a)$：动作的长期回报估计——越大越好
    - $-\alpha\log\pi(a|s)$：**熵项**——策略越「不笃定」（动作分布越均匀），扣分越少；温度参数 $\alpha$ 控制探索在目标里的权重
    - 合起来的直觉：不只挑回报高的动作，还要**保持随机性**——探索和鲁棒性都是白送的，这正是 SAC 样本效率高于 DDPG 的来源
    - 训练时双 Q 取小更新（式 19-21）；代价是结构复杂、超参难调、算力要求高
- 论文给出 Algorithm 3/4/5 伪代码（DQN / DDPG / SAC）

## 11. 算法应用分析要点（第 4.2 节）
- **查表 RL**（Q-learning/SARSA）：概念简单适合小规模 CSP；Wang 等用时变 Q 表缩减查找空间；Dang 等动作空间只有「充/放/不动」三个离散动作所以 Q-learning 高效；可作复杂方法的 benchmark
- **DQN 系**：Zhang 2020 在北京真实充电网络测试；Lee 2020 数据驱动动态定价（学真实数据集中充电桩对电价的响应模式）；Ye 2022 两阶段调度（集中再分配 + 分散功率控制）共享 Q 网络与回放池；大规模场景用 DDQN 稳定训练
- **连续动作系**：DDPG 直接控充电功率显著优于离散化 DQN；Ding 2020 把用户行为/天气/交通不确定性纳入模型；Wang 2023 DDPG+迁移学习加速收敛；SAC 采样效率高、已被证明在解质量与计算效率上胜过 DDPG（Yan 2021、Jin & Xu 2020），但算力与调参代价大
- **离线 RL**（4 篇全 FQI）：ISO New England 672 天数据；10 站一年真实数据且策略可免重训迁移到更多站
- **多智能体**（22 篇）：Han 2019 多智能体 Q-learning 做竞争市场多站利润优化；Qian 2021a 多智能体 DQN + **平均场理论**（Q 值按邻近两两交互分解、降低交互规模）；Shin 2019 CommNet 通信型多智能体；DDPG/SAC 也已扩展到多智能体（Zhang 2022c 两阶段能量采购+分配、Al Zishan 2020 / Sun & Qiu 2021 多智能体 SAC 削峰、Yan 2022 去中心化多智能体 SAC 免完全可观状态）

## 12. RL 优势 + 四步选型流程（第 4.2/4.3 节）
- RL 相对传统方法四条优势：①CSP 天然是离散时域 MDP；②克服大状态-动作空间、GPU 加速；③通用、免人工特征；④model-free
- **四步算法选型**（同样 MDP 有 DQN/DDPG/SAC/MA-DQN/MA-SAC 五种算法被随意选用、缺乏统一标准 → 综述给出决策树）：
  1. **单智能体 or 多智能体**？共享环境有多个利益相关方 → 多智能体（去中心化更贴近现实）
  2. **RL or DRL**？DRL 开发耗时、需专家调参；小规模 CSP 没必要用 DRL——按**交通网络规模**经验判断
  3. **在线 or 离线**？能在线交互选在线；在线采样不现实/有安全顾虑选离线
  4. **具体 DRL 算法**：离散动作 → DQN 及变体；连续动作 → DDPG/SAC（优于离散化 DQN）；RL 背景强 → DDPG（吃调参），否则 SAC（结构相对简单，但注意其复杂结构的调参与实现难度）

## 13. 讨论：三大扩展方向（第 5.1 节）
1. **CSP 专用 RL 算法**：现有研究直接搬其他领域（游戏/机器人）的通用算法；CSP 高度带约束，对采样效率要求更高，约束却不是游戏/机器人的主要关切
2. **真实充电特性**：纳入新充电技术（如无线充电会显著加速充电过程、改变服务能力与调度结果）
3. **可靠数字平台**：在线 RL 需要 EV-EVCS-电网实时交互的信息交换平台；多数研究假设实体间信息无缝交换，现实中很难（例：Savari 2020 的 IoT 实时负荷预测可避免第三方介入、保护隐私）

## 14. 五大挑战（第 5.2 节）
1. **高样本复杂度**：全部研究仅仿真验证、无实际部署；RL 初期探索对利益相关方代价不可接受
2. **高稀疏性与延迟**：多约束 CSP 奖励稀疏且延迟，采样轨迹常低质/无意义 → 奖励方差大
3. **超参敏感**：电价波动、需求变化、用户行为演化使固定超参难以适应持续变化的环境
4. **可扩展性**：训练成本高；有人把「训练后求解单个实例的运行时间」当计算效率——不合理，因为环境持续变化需频繁重训，训练成本不可忽略
5. **多约束处理**：两条路都难——惩罚不可行解 → 奖励更稀疏、训练更慢；约束并入统一奖励函数 → 设计困难，设计不当会 **reward hacking**（agent 以意料之外的方式刷高奖励）

## 15. 八个未来方向（第 5.3 节）
1. **离线 DRL**：batch-constrained DQN（BCQ）、quantile regression DQN 等离线算法已显示优于在线设定；高质量数据集（历史充电需求、EV 位置、电量、桩容量、电网约束）是前提
2. **迁移学习**：许多 CSP 问题设定相似，迁移已学策略/价值函数 → 提升样本效率、加速训练，实现在线交互可行
3. **POMDP**：复杂网络中充电需求难以完全观测；用 belief state 估计隐状态，处理 CSP 内在不确定性
4. **分层 RL**：现有动作空间大多只有单一动作，限制了调度性能；把任务分解为子问题（多动作层级结构）
5. **混合动作空间**：连续+离散变量并存（如两阶段：预约系统[离散] + 动态定价[连续]）；组合爆炸；**参数化动作空间**（parameterized action space）是可行解
6. **更先进的 DRL**：distributional DDQN、TRPO（REINFORCE 的信任域改进版；vanilla REINFORCE 在已综述文献中竟从未被直接使用）
7. **统一研究框架**：不同研究算法与指标各异无法标准化比较——需统一框架识别「特定场景下最有效的算法」
8. **高质量数据集**：一要可靠的在线信息交换平台（连结用户-充电站-电网，提供价格/队列等运营信息），二要**高保真充电调度仿真器**提供 benchmark 与数据集

> **补注｜未来方向里那一串算法名，逐个翻译**
> - **distributional DDQN（分布式 DQN）**：不只学「期望回报」$Q$，而是学回报的**整个分布**（一串分位数）。好处是能表达风险偏好——电网调度更关心「最坏情况别出事」，而不是平均收益。
> - **BCQ（Batch-Constrained deep Q-learning）**：离线 RL 经典算法，限制策略只能选「历史数据里出现过的动作**附近**」的动作，避免它去高估一个从没试过的动作。
> - **CQL（Conservative Q-Learning）**：同类思路的另一代表，直接在损失里**压低**数据分布之外动作的 Q 值（保守化）。2020 年后离线 RL 的主流基线，本文检索截止 2023-12 未覆盖。
> - **TRPO（Trust Region Policy Optimization）**：策略梯度 + 硬约束「新旧策略的 KL 散度 ≤ δ」，保证每次更新不把策略搞崩。第五篇的 PPO 用「概率比裁剪」近似它——同一思想，实现简单得多。
> - **参数化动作空间（parameterized action space）**：动作 = 「离散选项 + 该选项自带的连续参数」，记作 $a=(k,x_k)$，例如「充电(37 kW)」「放电(12 kW)」。这是第 5 条「混合动作空间」的标准解法，能避免把连续量硬离散化。
> - 顺带解释第 6 条里那个反常识的观察：**vanilla REINFORCE 在这 111 篇里竟一次都没被直接用**——因为它方差太大、无 critic 兜底，大家宁可上 DQN/DDPG。

## 16. 结论（第 6 节）
- RL+MDP 是解决传统方法难以处理的 CSP 的有前景控制范式；发文量 2020 年跃升后稳定；RL 正从「预测角色」扩展为「控制角色」
- 理论意义：为交通网络中复杂、动态、时空耦合的调度问题提供求解框架，可推广到其他充电网络规划运营问题
- 实践意义：电网运营商、充电服务商、用户实时优化调度——降成本、提电网可靠性、促 EV 融入交通生态、减碳

## 术语表
- **CSP（Charging Scheduling Problem，充电调度问题）**：考虑电价、电网负荷、车辆需求等动态因素，优化 EV「何时、何地、如何」充电的决策问题集合
- **EVCS（EV Charging Station，充电站）**；**SoC（State of Charge，电池荷电状态）**；**PLR（Peak-Load Reduction，削峰）**
- **MDP（马尔可夫决策过程）**：五要素 S 状态 / A 动作 / R 奖励 / P 策略 / H 地平线；马尔可夫性 = 状态已含全部历史信息
- **model-based / model-free**：是否需要环境转移概率与奖励的解析模型
- **on-policy / off-policy**：采样策略与被评价策略是否为同一个（后者可用经验回放，效率高但易过估计）
- **actor-critic**：actor 出动作、critic 打分，actor 沿 critic 的梯度更新；DQN 系只有 critic，故只能离散动作
- **自举（bootstrapping）**：用自身当前估计构造更新目标（TD 的 $R+\gamma V(s')$），是目标网络/软更新要解决的问题来源
- **平均场（mean field）**：把 $N^2$ 的两两交互近似为「与群体平均交互」，复杂度降到 $O(N)$；**CommNet**：多 agent 间可微通信信道（广播隐状态取平均）
- **直接法/间接法**：直接法 = 用户自愿参与、决策者可拒绝请求（直接控制、充电站推荐）；间接法 = 调充电价或充电功率引导需求
- **TD 学习**：用 $R_{t+1}+\gamma V(s')$ 引导更新当前估计的时序差分方法
- **SARSA**：on-policy TD 控制，用实际执行的下一动作更新；**Q-learning**：off-policy，用贪心 max 更新
- **REINFORCE**：蒙特卡洛策略梯度，整轨迹采样、高方差；减 baseline 可降方差不引偏
- **FQI（Fitted Q-iteration）**：对静态数据集反复做 Bellman 回归迭代的离线 RL 算法
- **马尔可夫博弈 / Nash Q-learning**：多智能体 RL 的博弈论框架；解概念为纳什均衡（无人可单方面获益）
- **DQN**：Q-learning + DNN + 经验回放 + 目标网络；**DDQN**：双网络去过估计；**D4QN**：Dueling 架构分解状态价值与动作优势
- **DDPG**：actor-critic、确定性策略、连续动作空间；**SAC**：最大熵 + 双 Q 取小，采样效率高但结构复杂
- **POMDP（部分可观 MDP）**：观测不完整，需维护 belief state 估计隐状态
- **分层 RL**：将任务分解为子任务层级求解；**参数化动作空间**：处理「离散+连续」混合动作的方案
- **Reward hacking**：奖励函数设计不当导致 agent 以非预期方式获取高奖励

## 可借鉴点（结合车网互动场景）
1. **三立场框架 = 现成的选题定位工具**：用户（52.3%）/ 电网（41.4%）/ 运营（30.6%）三视角统计直接指出空白——**没有任何研究同时覆盖三个立场**；「电网视角 2022 年后反超」说明车网互动（V2G）正是当前热点入口
2. **四步选型流程可直接用于大创/论文的方法设计**：先定单/多智能体（多利益方→多智能体）、再按网络规模定 RL/DRL、按能否在线交互定在线/离线、最后按动作空间性质定算法（离散 DQN 系、连续 DDPG/SAC）
3. **状态/动作统计 = MDP 设计的「市场调研」**：SoC + 电价 + 充电速率是领域最大公约数，做自己的模型时从这套基线出发再按需扩展（对照第二篇：状态 = 时间片 + 各设施利用率/QoS，动作 = 连续价格向量——正是「运营立场 + 间接法 + 连续动作 → SAC/TD3 系」的一个实例）
4. **与第二篇互相印证**：第二篇的「目标+约束 → 乘性奖励惩罚 + 安全余度 ζ」正是本综述挑战 5（多约束 reward 设计）的一种工程解法；综述点名的 reward hacking 风险，对应第二篇把惩罚项直接从约束翻译过来以避免 hacking 的设计逻辑
5. **写综述的方法论模板可迁移**：布尔检索式 → 漏斗筛选（755→384→151→111）→ 五维度分析（目标/状态/动作/算法/训练策略）→ 挑战 → 方向；写自己的综述（如共享 EV 经济性优化）时照此骨架填内容
6. **未来方向 1+8 是数据侧机会**：离线 DRL + 高保真充电仿真器 + 公开数据集（ISO New England、一年 10 站数据已是先例）——如果大创能拿到真实充电运营数据，离线 RL 是差异化切入点
